# D4 Overflow Decision

Decision for this patch: defer scrolling/clamping beyond the published fixture envelope. Natural-height sizing is retained.

The supported local envelope covers four model rows, a 24-character wide ASCII label, a Unicode robustness label, maximum declared Extra Usage numbers, every cached banner, long three-line error text, both NoAuth installation branches, recovering text, and Game Over combinations. Detached fitting and the real local shown-popover harness report finite 320-point-wide roots with no allocation dependence.

This is a local implementation decision, not final small-display evidence. The required physical 1x/small-display runner is missing, so release remains blocked by E0-R. If that runner shows the supported fixture exceeding `visibleFrame` after real arrow/edge clearance, scrolling/clamping becomes a blocking follow-up before release rather than being silently clipped.
